Playlist Studio

Sube tus propios archivos de audio, organízalos en listas y exporta un paquete para guardarlo o usarlo en tu proyecto.

1. Añadir música

3. Escuchar y exportar

Selecciona una canción de la biblioteca para escucharla.

El ZIP incluye el JSON y los archivos de audio dentro de una carpeta audio/. El JSON solo, por sí mismo, no contiene la música. El ZIP está pensado como paquete de exportación; para usarlo en AeroSim, habrá que alojar sus audios en URLs públicas HTTPS o adaptar AeroSim para leer el paquete.

Las playlists y los audios se guardan en el almacenamiento de este navegador. Exporta un ZIP para hacer una copia de seguridad; el navegador puede borrar datos si limpias sus datos. Esta página no distribuye música: usa archivos que tengas derecho a utilizar.
